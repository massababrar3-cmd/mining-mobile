BRAVUS — GITHUB PAGES / ON-DEVICE EDITION 2.2

UPDATE EXISTING WEBSITE:
1. Download Mining-Operations-GitHub-Pages-2.2.zip and Extract All on your laptop.
2. Open your public mining-mobile repository, branch main.
3. Code > Add file > Upload files > upload/replace index.html > Commit changes.
   For a new website, upload all four extracted files at the repository root.
4. Settings > Pages > Deploy from a branch > main > / (root). Await success.
5. Open GitHub's Visit site link. Refresh and check footer: On-device Edition 2.2.

OPERATE ON LAPTOP / IPHONE:
1. Open the HTTPS website in Windows Chrome or iPhone Safari. No installation.
2. Enter First Name / Surname and choose the relevant inspection or handover.
   FRM-224 Mining, FRM-447 Dozer Push, FRM-440 Pump, FRM-441 Infrastructure,
   and FRM-431 Drill & Blast load automatically. No JSON import is required.
3. Start report > complete required details, compliance answers and comments.
4. Use Take a photo / Choose pictures; camera permissions depend on the device.
5. Draw your signature. Optional/required second sign-off has its own name.
6. Complete & generate PDF > Download PDF. Source inspection PDFs use the original
   Bravus logo, embedded Lato fonts, source colours, column proportions, Y/N/N/A
   tables, source identifiers and sign-off/evidence. Long answers/photos add pages.
7. Windows: Prepare Outlook draft with PDF > check sender/recipient > download EML >
   open in compatible Outlook > check attachment > Send. If unsupported, manually
   attach the downloaded PDF to a new Outlook message. No automatic send.
8. iPhone: Share PDF > Outlook or Save to Files, then attach/send in Outlook.
9. SharePoint: configure permitted folder > Open SharePoint folder > company login >
   Upload > Files > select saved PDF. No automatic upload.
10. Save/share before Clear report / finish. Closing/reloading loses unsaved work.

PRIVACY / LIMITS:
- Inspection questions, company template branding and website code are public.
- Entered personnel, answers, photos, signatures and PDFs are processed in memory.
  No report history, cookies, browser database, upload connection or analytics.
- Downloaded/shared files, camera originals and OS/browser snapshots remain outside
  these page-memory controls. The host receives normal website connection logs.
- Names and device time are declared; there is no real login or owner-only control.
- Session template edits include revised/new questions in exported source-style PDFs.
- PDF is a programmatic recreation of Word styling, not an identical Word-rendering
  engine. Evidence and content alter pagination. Check your actual printed reports.
- Actual iPhone camera/Outlook and live SharePoint delivery need device acceptance.
