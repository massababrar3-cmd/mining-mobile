FREE WEBSITE / NO DEVICE INSTALLATION:
1. Extract Mining-Operations-GitHub-Pages-2.1.zip.
2. Create a SEPARATE public GitHub repository for ONLY these four files:
   index.html, .nojekyll, robots.txt, OPEN-ON-IPHONE.txt.
   Code > Add file > Upload files > Commit changes.
   Do not upload the ZIP as the website and do not upload the full Software repo.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait for GitHub to show a successful deployment and actual published URL.
   Open that same HTTPS link in Windows Chrome or iPhone Safari/Chrome.
   Safari > Share > Add to Home Screen is optional. No Node.js is required.
5. Enter First Name/Last Name and select a handover/inspection. Starter inspections
   are configurable generic templates, not the supplied company Word forms.
6. To use company questions: Templates & delivery settings > Import private
   source-form JSON > choose privately supplied FRM-*.json files > Apply.
   The questions stay in this browser session. Never upload these JSON files,
   private configuration exports or completed reports to the public repository.
7. Start report > answers/comments > take/choose JPEG/PNG/WebP photos.
   HEIC needs conversion or Most Compatible camera format. Max 12 photos/report.
8. Draw your signature with finger/mouse/pen. Second signature is supported when
   configured/imported; required second sign-off needs its own declared name.
9. Complete & generate PDF. PDF includes answers/pictures/signatures, declared
   personnel and time from the device clock. Filename includes DD-MM-YYYY.
10. iPhone: Share PDF > Outlook or Save to Files. Check recipient, PDF and Send.
    If file sharing is unsupported, Download PDF and manually attach in Outlook.
11. Windows: Prepare Outlook draft with PDF > check requested sender/recipient >
    download .eml > open in compatible desktop Outlook > inspect attachment > Send.
    Outlook version compatibility remains device testing. If not editable/openable,
    Download PDF > Outlook > New mail > Attach file. Sender edits grant no permission.
12. SharePoint: paste permitted HTTPS folder URL > Open SharePoint folder > company
    login > Upload > Files > saved PDF. No automatic send/upload receipt is provided.
13. Clear report / finish only after saving/sharing. Reload/close loses current work.
