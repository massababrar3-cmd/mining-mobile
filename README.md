Deployment files for the maintenance-only page at
https://massababrar3-cmd.github.io/mining-mobile/ .

Hosting status at the 18 November 2026 handover: Pages is disabled and the URL
returns 404. The connected integration can push code but cannot enable Pages.
A repository administrator must enable Settings > Pages > Deploy from a branch,
main, / (root), then verify the successful deployment and maintenance page.

Development and tests are maintained in the private
[massababrar3-cmd/Software](https://github.com/massababrar3-cmd/Software)
repository (`maintenance-site/`). Do not develop independently here or upload
the private application, reports, credentials or company configuration.

Existing encrypted drafts are retained locally. Deletion requires the existing
name and PIN/passphrase, followed by confirmation for each draft. No new reports,
profile creation, editing, PDF generation, delivery, or automatic data deletion.

The original public website remains in Git history and in the preserved private
IT handover archive. Source history has not been rewritten or deleted.
