[massababrar3-cmd/Software](https://github.com/massababrar3-cmd/Software)

name and PIN/passphrase, followed by confirmation for each draft. No new reports,
profile creation, editing, PDF generation, delivery, or automatic data deletion.

IT handover archive. Source history has not been rewritten or deleted.
